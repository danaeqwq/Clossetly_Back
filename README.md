Clossetly – Backend

Backend de Clossetly, una plataforma de moda circular que permite a los usuarios gestionar su armario virtual, publicar prendas para la venta o intercambio y descubrir prendas de otros usuarios.

Este proyecto forma parte del Trabajo Práctico Integrador (TPI) de 7mo 1ra Programación.

Tecnologías utilizadas

Node.js: entorno de ejecución de JavaScript.

Express: framework para desarrollar la API REST.

MySQL: sistema de gestión de bases de datos.

Axios: comunicación entre el frontend y el backend.

JWT (JSON Web Token): autenticación y validación de sesiones.

bcrypt: encriptación de contraseñas.

dotenv: gestión de variables de entorno.
